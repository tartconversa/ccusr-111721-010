# 跨机构数据协作台账

本服务记录数据来源、字段含义、合作许可、数据产品及交付凭据。合作方可在本地演练不同机构和法域之间的资料流转；示例记录均为虚构，不连接真实口岸或支付系统。

需要 Python 3.10 或更新版本，不依赖第三方包。

运行项目测试：`python -m unittest discover -s tests -v`。
检查源码：`python -m compileall -q exchange`。
演练入口：`python -m exchange --database demo.db`。

领域逻辑分布在来源目录、合作许可、产品编排、交付核验和撤回处置中。`exchange/service.py` 组合这些操作，`exchange/db.py` 保存本地 SQLite 表结构；调用接口和现有边界可从源码及测试读取。

## 合作结束后的处置

登记来源时可声明保存期限（`retention_until`）。`catalog.withdraw` 记录合作方撤回后，`disposal.execute` 依据来源约定、产品输入和已发出的交付凭据推导每份内容的处置范围：

- 来源资产：保存期限未满则**隔离**（原件留存，不再参与组装与交付），期限已满则**清理**（移除 payload，保留摘要）。
- 含该来源资产的产品修订：**封存**，不再交付；其他来源的资产、单方产品与交付不受影响。
- 含该来源资产的交付凭据：**标记撤回**。凭据只含摘要与元数据，不含受限内容，继续留存供核验。

每项内容的处置进度记录在 `disposal_items`，逐项提交；重复执行自动跳过已完成部分，中途失败后可再次执行续跑，并以 `disposal.status` 核对各项状态。全部操作写入审计日志。
